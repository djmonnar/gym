# 짐패스 UI 프로토타입

헬스장을 1년권이 아니라 한 달씩 구독하고 QR로 바로 입장하는 모바일 우선 PWA 스타일 프론트엔드 프로토타입입니다. 기존 `index`의 사진 자산과 피트니스 무드는 유지하면서, 네이비 + 라임 + 화이트 기반의 프리미엄 구독 플랫폼 톤으로 월구독, 동적 QR, PT, 루틴, AI 식단, 상품 주문, 관리자 검증 흐름을 더미 데이터와 로컬 상태로 구현했습니다.

## 실행 방법

```bash
npm install
npm run dev
```

개발 서버에서는 `http://localhost:5173/index.source.html`로 접속하면 됩니다.
특정 화면을 바로 확인하려면 `?screen=home`, `?screen=shop`, `?screen=shopDetail`처럼 화면 id를 붙일 수 있습니다.

## 배포 빌드

```bash
npm run build
```

빌드 결과는 `docs/`에 생성되고, GitHub Pages 루트 배포도 동작하도록 `index.html`, `assets/`, `images/`, `brand/`, `og/`가 함께 갱신됩니다.

## 기술 스택

- Vite
- React
- TypeScript
- Tailwind CSS
- lucide-react
- sharp 이미지 렌더링 스크립트

## 주요 화면

- 스플래시, 온보딩, 로그인, 위치 권한 안내
- 홈, 헬스장 검색/필터, 헬스장 상세
- 구독권 선택, 결제 확인, 결제 완료
- 내 이용권 QR, 구독 관리, 결제 내역
- 고객센터/환불 안내, 마이페이지
- PT 신청, 운동 루틴, AI 식단 맞춤
- 사장님 관리자 홈, 회원 목록, QR 확인
- GYMSHOP 상품 판매 패널, 닭가슴살 상세, 장바구니, 구매 완료

## 이번 보강 방향

- 기존 홈/검색 카드의 실제 사진과 피트니스 무드는 유지
- 메인 컬러를 `#111827`, 포인트 컬러를 `#D7FF3F`, 서브 컬러를 `#2563EB`로 정리
- 헬스장 리스트에서 월 가격, 거리, 운영시간을 즉시 비교
- 스플래시, 3단계 온보딩, 체험 로그인, 위치 안내로 이어지는 초기 진입 흐름을 보강
- 홈에서 구독 상태, 다음 결제일, QR 이용권 진입을 명확하게 노출
- 홈을 구독 상태, 오늘 루틴, AI 식단, PT 추천, GYMSHOP 상품을 한눈에 보는 개인 대시보드로 보강
- 헬스장 상세, 구독권 선택, 결제 확인, 결제 완료, QR 발급으로 이어지는 결제 전환 흐름을 고도화
- 이용권 화면에서 30초 카운트다운, 임시 토큰, 캡처 방지 안내를 표시
- 내 이용권 화면에 `checkin_token: gp_live_****_7K2M` 형태의 동적 QR 이용권 보안 UI를 보강
- 관리자 QR 확인에서 QR 검증 상태를 회원권 상태와 분리
- PT 상담, 주간 운동 루틴, 본사 식단표 기반 AI 식단 맞춤 화면 추가
- 실제 결제, 로그인, 지도 API, 백엔드 연동 없이 더미 데이터만 사용

## 동적 QR 보안 구조

- QR은 회원권 ID를 직접 담지 않고 `gp_live_****_7K2M`처럼 마스킹된 서버 검증용 임시 토큰만 보여줍니다.
- UI에서는 30초 카운트다운과 진행 바를 표시하고, 시간이 끝나면 더미 발급 회차가 갱신됩니다.
- “30초마다 새 QR이 생성됩니다”, “캡처한 QR은 사용할 수 없습니다”, “1회 스캔 후 토큰이 폐기됩니다” 안내를 이용권 화면에 배치했습니다.
- 실제 서버 검증, 토큰 발급, 토큰 폐기는 구현하지 않았고, 추후 API 연동이 쉽도록 UI 상태만 분리했습니다.

## 관리자 QR 검증 상태

기존 회원 상태(`이용중`, `만료예정`, `해지예약`, `만료`)와 별도로 QR 검증 상태를 분리했습니다.

- 입장 가능
- 만료된 QR
- 이미 사용된 QR
- 다른 지점 이용권
- 회원권 만료

각 상태는 관리자 QR 확인 화면에서 다른 색상, 안내 문구, 회원명, 회원번호, 이용권, 남은 기간, 지점 정보를 보여줍니다.

## 디자인 방향

- 네이비 + 라임 + 화이트 중심의 프리미엄 피트니스 구독 플랫폼 무드
- 모바일 앱 프레임과 플로팅 하단 탭바
- 구독 상태, 다음 결제일, QR 입장을 홈 첫 화면에서 즉시 확인
- 실제 이미지 자산을 활용한 홈 히어로, 상품 이미지, 카카오톡 공유 썸네일
- 카카오톡 공유 썸네일은 `public/og/kakao-thumbnail.svg`를 원본으로 `public/og/kakao-thumbnail.png`가 자동 생성됩니다.
- 추후 Firebase, 결제 SDK, 지도 API 연동을 위해 화면 상태와 더미 데이터를 `src/App.tsx`, `src/data/gympass.ts`, `src/types.ts`로 분리했습니다.

## 구조

```text
src/
  App.tsx                 전체 화면 라우팅과 로컬 상태
  components/ui.tsx       버튼, 카드, 배지, 앱 프레임, 하단 탭바
  data/gympass.ts         헬스장, 구독권, QR 검증, PT, 루틴, 식단, 관리자, 상품 더미 데이터
  types.ts                화면, QR 검증, PT, 루틴, 식단 데이터 타입
  styles.css              Tailwind 기본 스타일과 QR placeholder
public/
  brand/                  짐패스 로고와 PWA 아이콘
  images/                 헬스장/히어로/GYMSHOP 이미지 자산
  og/                     카카오톡 공유 썸네일
scripts/
  render-brand-assets.mjs  썸네일과 아이콘 PNG 생성
  publish-pages.mjs        GitHub Pages 루트 배포 파일 복사
```
